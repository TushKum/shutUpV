# Case studies

Three squads played through the whole night. Their key numbers are the platform's acceptance tests
(docs/BRIEF.md, tests 4–6), so the game reproduces them exactly. Use them in the 20:30 briefing, in training sessions
before the event, and at the help desk.

| Case | What it teaches |
|---|---|
| [A: AquaSense](AQUASENSE.md) | The full night done right: pitch → IPO → crisis → fee → deal → plan → flash → close, with every team's final value. |
| [B: CampusCart](CAMPUSCART.md) | Deadlines: the default fee at 01:05, a deal edited after signing, a 78 plan capped at 50. |
| [C: SnapStudy](SNAPSTUDY.md) | The AI price as an anchor, shorting, and collusion flag 1. |

Sample pitch, plan and flash answers (strong and weak, with the scores to expect) are in [../samples](../samples/).
